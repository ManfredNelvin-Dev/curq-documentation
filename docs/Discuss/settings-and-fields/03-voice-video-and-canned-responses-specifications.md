# Voice, Video, and Canned Responses Specifications

This document provides factual specifications, hardware parameter limits, diagnostic log structures, and template rules for real-time conferencing and canned responses in CURQ.

---

## Voice and Audio Parameters

Settings configured under **Discuss > Configuration > Voice & Video > Audio Settings**:

| Parameter | Options / Range | Description |
| :--- | :--- | :--- |
| **Input device** | System-detected hardware | Designates the active hardware microphone endpoint. (Default: `Browser default`) |
| **Audio Mode** | • Voice Detection<br>• Push to Talk | Determines how audio signals are captured and transmitted during calls. (Default: `Voice Detection`) |
| **Voice detection threshold** | `0%` to `100%` | Sensitivity ceiling required to activate transmission in Voice Detection mode. (Default: `5%`) |
| **Push-to-talk key** | Keyboard shortcut | Dedicated hardware shortcut held down to transmit audio in Push to Talk mode (e.g., `Space`, `Ctrl+Space`). |
| **Delay after releasing** | `0 ms` to `2000 ms` | Hold-open buffer applied after releasing the hotkey to avoid truncating sentence ends. (Default: `200 ms`) |

## Video Display and Privacy Parameters

Settings configured under **Discuss > Configuration > Voice & Video > Video Settings**:

| Setting | Allowable Values | Description |
| :--- | :--- | :--- |
| **Show video participants only** | Enabled / Disabled | Filters grid views to display only participants with active camera broadcasts. |
| **Blur video background** | Enabled / Disabled | Real-time browser canvas silhouette isolation and blur filtering. |
| **Background blur intensity** | `0%` to `100%` | Density of gaussian blur applied to surroundings behind the speaker. |
| **Edge blur intensity** | `0%` to `100%` | Softness gradient applied along the perimeter boundary of the speaker silhouette. |

## Technical Settings: WebRTC Diagnostic Log File Schema

The diagnostic export generated by clicking **Download logs** outputs a JSON object (`RtcLogs_YYYY-MM-DD_HH-mm.json`) structured as follows:

| Log Schema Key | Description |
| :--- | :--- |
| `timestamp` | Exact time mark of the WebRTC conference session (ISO-8601 format). |
| `connectionState` | ICE connection status (`new`, `connecting`, `connected`, `disconnected`, `failed`). |
| `iceServers` | STUN and TURN server endpoints utilized for NAT traversal. |
| `localCandidates` | Network address and protocol candidates offered by the local client. |
| `remoteCandidates` | Network address and protocol candidates offered by the peer connection. |
| `inboundRtpStreams` | Packets received, jitter (ms), round-trip time (ms), and packet loss percentage. |
| `outboundRtpStreams` | Packets transmitted, frame rate, resolution, and bitrate metrics. |

## Canned Response Field Specifications

Settings configured under **Discuss > Configuration > Canned Responses**:

| Field Name | Description |
| :--- | :--- |
| **Shortcut** | Unique keyword triggering autocomplete without spaces or leading colons (e.g., `terms`, `bank-details`). Triggered in chat by typing `:shortcut`. |
| **Substitution** | The verbatim replacement text, paragraphs, or links inserted into the message box. |
| **Description** | Explanatory title displayed in autocomplete menus to guide user selection. |
| **Authorized Groups** | Defines organizational visibility: leaving empty restricts template to the author; selecting user groups shares across members. |

### Canned Response Scopes:
* **Personal Scope**: `Authorized Groups` is empty. The template is visible, searchable, and executable strictly by the user who created it.
* **Shared Department Scope**: `Authorized Groups` contains one or more security groups (e.g., `Sales / User`). Any user belonging to at least one designated group has autocomplete access.
