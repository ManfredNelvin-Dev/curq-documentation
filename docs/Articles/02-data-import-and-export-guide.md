# Data Import & Export Guide

Migrating data into CURQ or exporting operational records for analysis is simple using built-in CSV and Excel utilities.

---

## 1. Importing Data into CURQ

### 1.1 Supported File Formats
CURQ supports **CSV (.csv)** and **Microsoft Excel (.xlsx)** file formats.

### 1.2 Steps to Import
1. Navigate to the target module list view (e.g. **Contacts**, **Products**, **Chart of Accounts**).
2. Click **Favorites > Import Records**.
3. Upload your `.csv` or `.xlsx` file.
4. Verify column mapping between your file columns and CURQ system fields.
5. Click **Test Import** to check for validation errors.
6. Click **Import** to finalize records creation.

---

## 2. Exporting Data from CURQ
1. Select the records you wish to export from any list view.
2. Click **Action > Export**.
3. Select desired fields or choose a saved export template.
4. Export as **Excel (.xlsx)** or **CSV**.
