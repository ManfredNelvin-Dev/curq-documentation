# User Roles & Permissions Setup

Role-based access control (RBAC) in CURQ allows enterprise administrators to define granular permission boundaries for staff across all modules.

---

## Default Access Groups

| Group Level | Access Scope |
|---|---|
| **User (Read Only)** | Can view assigned records and reports; cannot edit configuration or post financial vouchers. |
| **Standard User** | Full operational privileges within designated assigned departments. |
| **Manager** | Full operational access plus approval permissions, batch actions, and department reporting. |
| **Administrator** | System-wide configuration, access control management, and global audit logs. |

---

## Configuring User Access
1. Go to **Settings > Users & Companies > Users**.
2. Open the user record.
3. In the **Access Rights** tab, select the role level for each module (Accounting, CRM, Sales, HR, etc.).
4. Save the user record to apply permission rules immediately.
