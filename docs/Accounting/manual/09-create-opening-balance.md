Opening balance sheet

When setting up an accounting system, it is common to start with an ****opening balance sheet****. This provides the starting point for the accounting records and is often prepared in collaboration with an ****accountant****.

If you are starting a new business, the assets you invest in the company can be recorded in the ****opening balance sheet****. For existing companies switching to CURQ, the previous accounting balances can also be transferred using an opening balance sheet.

The opening balance is entered as a ****journal entry****.

Navigate to:\
****Invoicing → Accounting → Journal Entries****.

![](Pictures/10000001000004D2000002BB4241B31E.png){width="6.6929in" height="3.7909in"}

Then click the ****New**** button.\
The ****journal entry form**** will appear, where you can enter the opening balance details.

- ![](Pictures/10000001000004CB000002E146982ED9.png){width="6.6929in" height="4.0201in"}****Reference:**** Enter a clear description so it is easy to identify the purpose of the entry.
- ****Accounting Date:**** This is the date of the journal entry. For an opening balance, the end of a period is usually selected, often ****December 31**** for most companies. If you are switching to CURQ during the year, use the ****last day of the previous month****. If you are unsure which date to use, consult your ****accountant****.
- ****Journal:**** Select the journal that will be used for this entry.

After filling in these fields, enter the ****details of the opening balance**** in the ****journal entry lines****.

![](Pictures/10000001000004B2000001B4F804ED8D.png){width="6.6929in" height="2.4272in"}

- ****Account:**** Select the ****ledger account**** for the entry.
- ****Partner:**** Add a ****partner (customer or supplier)**** if the opening balance includes outstanding invoices. Create a separate line for each partner. If there are many entries, it may be clearer to create ****separate opening balance entries****, for example one for customers and one for suppliers.
- ****Label:**** Enter a clear description for the entry. If you include outstanding invoices, you can enter the ****invoice numbers**** here.
- ****Debit:**** Enter the amount on the ****debit side****.
- ****Credit:**** Enter the amount on the ****credit side****.

The opening balance entry can only be saved when it is ****balanced****. Before saving, make sure that the ****total debit and credit amounts are equal****. CURQ shows the totals of both columns at the bottom of the screen.
